# Regexes (case-insensitive) that must never appear in lines this fork ADDS on
# top of upstream. One per line; # starts a comment.
#
# THIS REPOSITORY IS PUBLIC, and so are its CI logs. Do not add your own
# hostnames, project code names, or team names here, and do not feed them in
# through FORK_GUARD_EXTRA_PATTERNS either: a pattern that matches gets its
# source printed, so the first breach would publish the very string you were
# hiding. (The CI path prints only file names for the same reason.)
#
# That leaves this list generic on purpose. It is a safety net for the obvious
# shapes, not a filter that understands your organisation. Keeping
# project-specific code out of core stays a human decision, made at review
# time, with the disposition label as the prompt.

# Private network addresses hard-coded into core
\b10\.\d{1,3}\.\d{1,3}\.\d{1,3}\b
\b192\.168\.\d{1,3}\.\d{1,3}\b
\b172\.(1[6-9]|2\d|3[01])\.\d{1,3}\.\d{1,3}\b

# Intranet-only hostname shapes
https?://[a-z0-9.-]*\.(internal|intranet|corp|lan|local)\b
https?://[a-z0-9.-]*\.(int|priv)\.[a-z]{2,}\b

# Credentials that should never be committed anywhere
\b(api[_-]?key|secret|passwd|password|token)\s*[:=]\s*["'][^"']{12,}["']
